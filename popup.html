PR Review Collector

Scrape PR review comments from GitHub, assign a human decision to each one, and copy a structured prompt for Claude.
Quick start
  1. Open a GitHub Pull Request
  2. Click the 📋 button (bottom-right)
  3. Pick a decision for each comment
  4. Choose a commit strategy
  5. Click Copy to clipboard
  6. Paste into Claude
Decisions
Fix
Change the code to address the comment
Ack
Acknowledge; no code change needed
Explain
Investigate and explain what the comment refers to (e.g. how a bug could occur, what a suggested feature would entail)
Ignore
Skip entirely — excluded from the prompt
Other
Custom action described in the note field
